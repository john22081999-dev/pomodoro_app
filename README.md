# Pomodoro Timer

A desktop Pomodoro productivity timer built in Python with tkinter.

## Features

- 25-minute work sessions with 5-minute short breaks and a 20-minute long break
- Automatically cycles through work and break periods
- Visual countdown on a tomato graphic
- Check marks track completed work sessions
- Reset button to start over

## Built with

- Python 3
- tkinter (GUI)

## How to run

Run the app: `python main.py`

(tkinter comes built into Python - nothing extra to install.)
